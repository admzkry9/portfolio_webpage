# Adam Zikry Portfolio

A static portfolio website built with HTML, CSS and JavaScript.

## Open in VS Code

Open this entire folder in VS Code.

For local development, use the VS Code "Live Server" extension or another local web server.

Do not rely on opening index.html directly with file:// when testing all features.

## Project structure

- index.html — main portfolio page
- style.css — styling and responsive layout
- script.js — tabs, carousels, video playback and animations
- 404.html — fallback page
- robots.txt — search engine crawling rules
- sitemap.xml — search engine sitemap
- site.webmanifest — web app metadata
- assets/ — images, videos and project files
- resume/ — place your resume PDF here
- favicon/ — place your favicon files here

## Adding projects

Open script.js and edit the WORKS object.

Example:

{
  title: "Unity Inventory System",
  tag: "C# / Unity",
  src: "assets/videos/unity-inventory.mp4",
  poster: "assets/images/projects/unity-inventory.jpg"
}

## Before deployment

1. Replace YOURDOMAIN.com in index.html, robots.txt and sitemap.xml.
2. Add your real resume PDF to resume/Adam_Zikry_Resume.pdf.
3. Add your real project videos/images.
4. Add your favicon files.
5. Add assets/images/og-image.jpg for social previews.
6. Test on desktop and mobile.
